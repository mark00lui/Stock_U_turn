# 基本面分析 — 2026-05-12

## 市場財報季概況

台股 2026-Q1 財報季已大致告一段落，整體上市櫃企業 EPS 年增約 22%，AI 伺服器、HBM/DDR5 記憶體、CCL 載板、被動元件、半導體設備為主要成長動能。2026-04 月營收公告期間落於 5/10 前後，半導體封測 (台積電鏈、AI ASIC 鏈) 與 PC/伺服器零組件廠多數延續雙位數 YoY 成長，記憶體/利基 DRAM 報價自 Q1 起連三季調漲。

警示：航運、紡織、傳產 OEM 仍受美中關稅及匯率干擾，部分被動元件廠庫存回補後恐面臨基期墊高壓力。本日 82 檔訊號股以 AI / 半導體 / 記憶體 / 電源管理 / 被動元件鏈為主，基本面普遍偏中性偏多。
