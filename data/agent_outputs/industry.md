# Industry Analyst — 2026-05-04

## Sector Overview
2026 Q2 台股產業景氣兩大主軸：
1. **AI 算力 + 電力 (擴張中)**：PCB 載板 / CCL / 散熱 / Server 連接器 / 重電變壓器 / 半導體設備，景氣擴張中段，能見度至 Q4。
2. **記憶體與封測 (復甦中)**：DRAM / NOR Flash / HBM 衍生，2026 Q1 觸底後正在回升，毛利率/ASP 改善。

弱勢：消費電子下游 (鞋材 9910 豐泰、LCD 5371 中光電) 仍處衰退末段。航運 (2603 長榮) 在景氣低點末段，運費反彈但 Q2 EPS 仍承壓。
