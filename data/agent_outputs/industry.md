## 三、中期展望 (各產業情境)

### A. AI ASIC / 矽智財 — 強烈看多 (評分 5)
- **驅動**：Google TPU v6 / AWS Trainium 3 / Meta MTIA v2 設計定案，2026H2 量產，**祥碩 (5269)**、**譜瑞-KY (4966)** 直接受惠。
- **數據點**：北美四大 CSP 2026 CapEx 共識升至 USD 280B (+34% YoY)，ASIC 佔比由 18% 升至 27%。
- **風險**：客戶集中度高、設計 win 後仍須驗證良率。

### B. 高速 / 高頻 PCB · CCL — 強烈看多 (評分 5)
- **驅動**：GB300 NVL72 / Rubin Ultra 對 M8 級高速 CCL 用量翻倍；**金像電 (2368) · 健鼎 (3044) · 楠梓電 (2316)** 訂單能見度延伸至 2026Q4。
- **數據點**：M8 CCL 報價 2026Q2 漲價 8~12%，下游同步轉嫁。
- **風險**：M7 → M8 轉換期良率學習曲線。

### C. AI 伺服器代工 / 電源 / 散熱 — 看多 (評分 4)
- **驅動**：英業達 (2356)、微星 (2377) 切入 GB300 與 ASIC 機櫃；康舒 (6282) 高壓電源模組打進 Blackwell 平台。
- **觀察**：毛利率被代工模式壓縮，需用營收成長率而非 GM 衡量。
- **風險**：GB200 與 GB300 過渡可能造成 2026Q2 出貨真空期。

### D. 被動元件 (MLCC / 電容 / 連接器) — 看多 (評分 4)
- **驅動**：華新科 (2492) · 鈺邦 (6449) · 日電貿 (3090) · 昇貿 (3305) 同步突破。AI Server 單機 MLCC 用量 vs 一般 Server **倍數成長**，連續第三季去庫存結束。
- **數據點**：MLCC 12 月 BB ratio 已升回 1.15。
- **風險**：中國競品報價戰持續。

### E. 半導體封測 / 測試 / 設備 — 看多 (評分 4-5)
- **滿星共振：2441 超豐、3587 閎康、6223 旺矽、3583 辛耘、7734 印能科技、2467 志聖、8021 尖點**
- **驅動**：CoWoS 產能 2026 由 36k → 75k wpm，週邊探針卡 (旺矽)、研磨拋光 (辛耘)、雷射 (印能) 全部受惠。**閎康 (3587)** 失效分析需求源於 HBM3e/HBM4 量產良率測試。
- **風險**：CoWoS-L 良率優化進度。

### F. 電子紙 / EPD — 看多 (評分 4)
- **元太 (8069) 滿星共振**：電子標籤 (ESL) 滲透率升至 18%，零售業全面導入；彩色電子紙 Gallery 系列 2026H2 起量。
- **風險**：終端零售景氣若衰退會減緩 ESL 採購。

### G. 工具機 / 自動化 — 中性偏多 (評分 3)
- **新代 (7750) · 所羅門 (2359)** 受惠機器人 + AOI 自動化需求。
- **風險**：傳產 CapEx 仍未回升，主要靠半導體訂單支撐。

### H. 通訊 / 電信 (防禦型) — 中性 (評分 3)
- **中華電 (2412) · 台灣大 (3045)** 突破：屬「資金停泊」現象 — 月線多頭 + 殖利率防禦。在大盤回檔時相對抗跌，但上漲空間有限。
- **訊芯-KY (6451)、智易 (3596)**：屬 AI 衍生網通基建，看好。

### I. 紡織 / 運動鞋 — 中性偏多 (評分 3-4)
- **豐泰 (9910 reversal 訊號)、聚陽 (1477)、巨大 (9921)**：Nike / Adidas 庫存結束、自行車 EU 庫存正常化；反映「全球消費品復甦」訊號正在浮現。
- **風險**：美國關稅政策不確定性 (Trump 2.0 對東南亞紡織關稅可能)。

### J. 生技醫療 — 中性 (評分 3)
- **藥華藥 (6446) 滿星突破**：Ropeg 美國 P. vera 適應症放量；個股題材獨立於產業景氣，視為單兵事件。

### K. 食品民生 — 中性 (評分 3)
- **統一 (1216)、卜蜂 (1215)**：黃豆 / 玉米成本回穩 + 中國消費政策刺激；屬「資金避險 + 大型權值股月線突破」，非結構性看好。

### L. 鋼鐵 / 金屬加工 — 中性偏多 (評分 3-4)
- **聯友金屬-創 (7610)、亞泰金屬 (6727)、金益鼎 (8390)**：金屬回收 + 特殊鋼 + Server 機構件鋼料需求；非鋼鐵本業景氣，而是「AI 機殼 / 機構鋼料」題材。

### M. 光學 / 觸控 — 中性偏多 (評分 3)
- **大立光 (3008) · TPK-KY (3673) · 正達 (3149)**：iPhone 17 Pro 潛望式鏡頭升級 + Vision Pro 2 玻璃供應商；題材集中於 2026H2 拉貨。
- **風險**：智慧型手機整體出貨仍持平 (1.18B 部)，依賴 ASP 升級。
