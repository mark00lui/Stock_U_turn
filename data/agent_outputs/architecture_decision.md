# CTA 系統架構決議 -- 2026-04-17 全員會議紀錄

## 1. 問題診斷：為什麼四段選股不同？

根本原因：**四個模組各自對 1000 檔股票池獨立排序，沒有共同的輸入漏斗。**

| 模組 | 排序依據 | 結果 |
|------|----------|------|
| Section 1 訊號掃描 | RSI 超賣反彈 + MACD 金叉，按星等排序 | 技術面最弱勢但出現反轉跡象的股票 |
| Section 2 基本面 | 月營收 YoY、EPS、毛利率，按財務健康度排序 | 財報最亮眼的股票（通常是強勢股，不會超賣） |
| Section 3 整合評分 | 技術 40% + 基本 30% + 產業 30% 加權 | 理論上的交集，但因各維度候選池不同，實際是各拉各的 |
| Section 4 回測持倉 | 歷史模擬，幾天/幾週前依訊號進場 | 過去式，不是今天的推薦 |

這四組「應該」不同，因為它們回答的是不同問題。問題在於：**報告沒有告訴讀者這四組之間的關係，也沒有收斂到一個明確結論。**

## 2. 兩種架構選項

### 選項 A：串聯漏斗 (Single Funnel)

```
1000 檔 → 技術訊號篩選（約 15 檔）→ 基本面過濾（約 8 檔）→ 產業過濾（約 5 檔）→ 最終名單
```

- 每一步只在前一步的結果中篩選，報告從頭到尾追蹤同一批股票
- 優點：邏輯清晰，讀者不會困惑，「到底要買誰」一目了然
- 缺點：基本面與產業分析被限制在極小的池子裡（15 檔），LLM agent 的廣視野優勢被浪費；若技術面當天只有 3 檔訊號，後面兩關可能全滅

### 選項 B：並聯分析 + 最終交叉 (現行改良)

```
技術訊號（15 檔）──┐
基本面 Top 10 ────┼─→ 三維交叉 → 最終名單
產業面 Top 10 ────┘
```

- 各維度獨立分析全市場，最後取交集或加權合併
- 優點：不遺漏純基本面機會，資訊量豐富
- 缺點：讀者必須看到最後一段才知道結論，中間段落各說各話

## 3. 推薦架構：選項 A 串聯漏斗

**理由：CTA 抄底反轉策略的本質決定了技術面必須是第一道門。**

我們的策略核心是「RSI/MACD 反轉訊號」，不是基本面選股。一檔股票財報再好，如果沒有出現超賣反彈訊號，它就不在我們的射程內。基本面和產業面的角色是「驗證」而非「發現」——驗證技術訊號是否有基本面支撐，而不是獨立推薦另一組股票。

具體流程改為：

1. **訊號掃描**：從 1000 檔中篩出今日 RSI/MACD 反轉訊號（約 10-20 檔）
2. **基本面驗證**：Revenue Analyst 只針對這 10-20 檔查月營收與財報，標註 A/B/C/D 等級
3. **產業驗證**：Industry Analyst 只針對這 10-20 檔的所屬行業評分，標註景氣位置
4. **整合評分**：Chief Strategist 對同一批股票做三維加權，排出最終名單
5. **交易計畫**：Trader 針對最終名單制定進出場計畫

這樣報告從頭到尾追蹤同一批股票，越篩越精，讀者不會迷路。

## 4. 回測 vs 實盤的定位

| | 回測持倉 | 實盤操作建議 |
|--|---------|------------|
| 本質 | 歷史模擬，驗證策略邏輯是否有效 | 今天該做什麼 |
| 進場時間 | 過去幾天/幾週 | 明天開盤 |
| 用途 | 策略績效指標（勝率、PF、MDD） | 具體交易計畫 |

回測區應獨立為「策略績效儀表板」，展示勝率、獲利因子等統計指標，讓讀者評估策略可信度。它不應與今日訊號混在一起，也不應被誤讀為「持倉建議」。

「明日操作計畫」的定義應為：**今日新出現的技術訊號，經基本面與產業面驗證通過，且尚未在回測持倉中的標的。** 若全部已在持倉中，則明確標示「無新候選，持續持有現有部位」。

## 5. 報告排版建議

基於串聯漏斗架構，報告重組為：

1. **今日訊號漏斗**：1000 檔 → N 檔訊號 → 星等分布表（這是起點）
2. **三維驗證**：針對上述 N 檔，逐檔列出技術分 / 基本面等級 / 產業評分（同一張表）
3. **最終推薦**：通過三維驗證的 Top 5，附風險等級與簡要理由
4. **明日操作計畫**：新建倉候選 + 現有持倉異動警示
5. **策略績效儀表板**：回測統計指標（獨立區塊，標明是歷史模擬）
6. **附錄**：完整持倉明細（可折疊）

核心原則：**讀者從第 1 段到第 4 段，追蹤的是同一批股票，不會出現「換了一組人」的困惑。**
